# JunctionScope Single-Cell RNA-seq Analysis Pipeline

## Overview

This repository contains the R pipeline used for single-cell RNA sequencing (scRNA-seq) analysis of T cells with integrated splice junction quantification. The workflow combines standard Seurat preprocessing with Harmony batch correction and custom splice junction analyses generated by JunctionScope. It was developed to investigate T-cell transcriptional states, CD45 isoform usage, alternative splicing, and treatment response in melanoma patients undergoing immune checkpoint blockade. :contentReference[oaicite:0]{index=0}

The pipeline performs:

- Quality control of single-cell RNA-seq data
- Normalization and variable feature selection
- PCA and Harmony batch correction
- UMAP visualization
- Graph-based clustering at multiple resolutions
- Cell-type annotation using canonical marker genes
- Quantification of CD45 and other splice isoforms
- Differential expression analysis between responders and non-responders
- Generation of publication-quality figures
- Export of processed Seurat objects and raw data

# Analysis Workflow

## 1. Quality Control

The pipeline calculates:

- Number of detected genes
- Total UMI counts
- Percent mitochondrial reads
- Percent ribosomal reads
- Percent hemoglobin reads

Cells with fewer than 200 detected genes are removed.

---

## 2. Normalization

Gene expression is normalized using

```r
NormalizeData()
```

---

## 3. Variable Feature Selection

Highly variable genes are identified using

```r
FindVariableFeatures()
```

Parameters:

- Method: VST
- Number of features: 3000

---

## 4. Data Scaling

```r
ScaleData()
```

---

## 5. Principal Component Analysis

```r
RunPCA()
```

---

## 6. Batch Correction

Samples are integrated using Harmony:

```r
RunHarmony(
    group.by.vars = "donor"
)
```

---

## 7. UMAP

Low-dimensional visualization is generated using

```r
RunUMAP()
```

---

## 8. Clustering

Cell neighborhoods are constructed using

```r
FindNeighbors()
```

Clusters are generated at multiple resolutions:

```
0.1
0.2
0.3
0.5
1.0
```

using

```r
FindClusters()
```

---

## 9. Marker Gene Visualization

The pipeline generates FeaturePlots and DotPlots for representative markers including:

- T cells
- CD4 T cells
- CD8 T cells
- γδ T cells
- Regulatory T cells
- NK cells
- Cytotoxic markers
- Exhaustion markers
- Stemness markers
- Tissue residency markers
- Trafficking markers

---

## 10. Splice Isoform Quantification

Isoform proportions are calculated for:

### CD45

- CD45RA
- CD45RB
- CD45RC
- CD45RO

### CD74

- Exon 7 inclusion

### CCL5

- Exon 3 inclusion

### XBP1

- Spliced
- Unspliced

Each cell is assigned its dominant CD45 isoform.

---

## 11. Differential Expression

Pre-treatment and post-treatment CD8 T cells are compared between Complete Responders (CR) and Non-Responders (NR).

Genes analyzed include:

```
BCL11B
TCF7
BACH2
SATB1
CXCR3
TOX
LAG3
PDCD1
CTLA4
HAVCR2
TIGIT
PRF1
GZMB
TNF
```

Differential expression is assessed using the Wilcoxon rank-sum test.

# Running the Pipeline

Load the Seurat object:

```r
library(Seurat)

Yost_Tcell_combined_seurat <- readRDS(
    "Yost_Tcell_combined_seurat_20260707.rds"
)
```

Run the analysis:

```r
source("scripts/analysis.R")
```
